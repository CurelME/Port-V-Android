# Port-V Android

An Android port of Grand Theft Auto V based on the WebAssembly (WASM) port, designed to run on modern Android devices with native Vulkan rendering.

## Features

- Native Vulkan Rendering: Custom-built graphics pipeline utilizing native Vulkan rendering.
- Turnip Driver Support: Custom Adreno Turnip Mesa driver support for Snapdragon processors.
- Touch & Gamepad Controls: Fully customizable on-screen touch controls and physical controller support.
- Multi-Language Support: Support for 12 localized UI and subtitle languages.

## Installation

Download the latest APK build from the [Releases](https://github.com/CurelME/Port-V-Android/releases) tab and install it on your Android device.

## Requirements

- Android 10 or newer
- Qualcomm Snapdragon processor is recommended
- Data from mirror folder of WASM port (get your own)

## Disclaimer

This repository hosts only the Android port runner executable. It does not distribute any copyrighted game assets, audio, textures, or proprietary code. Users must provide their own data from the WASM port mirror.
